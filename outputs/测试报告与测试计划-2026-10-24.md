## 三、测试方法与经验（供后续复用）

1. **登录态注入**：API 直登（GET `/api/auth/captcha` 解析 SVG `<text>` 字符 → POST `/api/auth/login`）拿 token → 浏览器同时设 cookie `token` 与 `localStorage.token`（前端 getToken 只读 localStorage，缺一不跳转）。
2. **KV 会话注入不可用**：经代理 API 写入的 KV key 不传播到 Worker 请求边缘（25 分钟 401）；worker 自身写入的会话立即可读——所以「真实登录」可用、「注入会话」不可用。
3. **agent-browser 陷阱**：daemon 不跨 Bash 命令存活，所有步骤须单条命令链；antd Segmented 隐藏 radio 点不动，用 `eval` 触发 label `.click()`；React 受控输入要用 native setter + input 事件；表格 tbody 首行可能是表头行，找按钮要先 `find(r=>r.querySelectorAll('button').length)`。
4. 测试残留：模板创建/删除、client_error 各一条审计记录（属正常审计行为，非数据污染）。
