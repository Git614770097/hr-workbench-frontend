## 修复：简历预览 iframe 显示成项目首页（2026-09-18 晚）
- 根因（已在生产环境用 curl 实证）：wrangler.jsonc 的 assets 配置了 SPA 模式后，**导航类请求**（Sec-Fetch-Mode: navigate，如 iframe/新标签页打开）被静态资产层直接拦截返回 index.html，不经过 Worker。普通 fetch（Sec-Fetch-Mode: cors）正常走 Worker。所以 API 都好使，唯独 iframe 预览挂。
- 实测：同一 URL，fetch 方式 → 401 application/json（Worker 响应）；iframe 导航方式 → 200 text/html（SPA 页面）。
- 修复：wrangler.jsonc assets 增加 `"run_worker_first": ["/api/*"]`，强制 /api/* 请求一律先走 Worker。
- 注意：@cloudflare/vite-plugin 部署时用的是构建期生成的 dist/hr_workbench/wrangler.json（由 wrangler.jsonc 重定向生成），改 wrangler.jsonc 后必须重新 vite build 再 deploy 才生效。已重新构建并确认生成配置包含 run_worker_first。
- 结论：这次连同重构一起，npm run deploy 一次即可全部上线（迁移 SQL 仍需先执行）。
